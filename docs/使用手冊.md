# twbacktest 台股回測系統 使用手冊

本系統用來回測台股**大盤（加權指數）**與**個股／ETF**的技術分析交易策略，
自動計算台股實際交易成本（手續費、證交稅），並輸出績效指標、圖表與交易明細。

> ⚠️ 回測結果只反映歷史資料在特定假設下的表現，不代表未來績效，也不構成投資建議。

## 1. 系統架構

```
white/
├── twbacktest/            主程式套件
│   ├── data.py            行情資料：Yahoo Finance → 證交所 → 本機快取，含自動退回近 5/3 年
│   ├── indicators.py      技術指標：SMA、EMA、RSI、MACD、布林通道、KD、通道突破
│   ├── strategies.py      8 種內建策略
│   ├── costs.py           台股交易成本：手續費（可打折、最低 20 元）、證交稅（股票 0.3%／ETF 0.1%）、滑價
│   ├── engine.py          逐日回測引擎：次日開盤成交、整張／零股、停損停利
│   ├── metrics.py         績效指標：CAGR、夏普、MDD、勝率、Alpha/Beta…
│   ├── report.py          產生圖表、CSV、JSON 與 HTML 報告
│   ├── runner.py          高階介面（單次回測、參數最佳化）
│   └── cli.py             命令列介面
├── tests/                 自動化測試
├── docs/使用手冊.md        本手冊
└── requirements.txt       相依套件
```

資料流程：

```
抓取行情 ──► 策略產生每日訊號 (0=空手, 1=持有) ──► 回測引擎模擬下單與扣成本 ──► 績效指標 ──► 報告
   ▲                                                                         ▲
   └──── 同時抓大盤（TAIEX）作為比較基準 ─────────────────────────────────────┘
```

## 2. 安裝

需要 **Python 3.10 以上**。

> 💡 本手冊的指令可以在 Windows 的「命令提示字元」或 PowerShell、macOS / Linux 的終端機直接逐行貼上執行。
> 兩邊寫法不同的地方會分開列出。

下載程式：

```
git clone https://github.com/brian20040424/white.git
cd white
```

建立並啟用虛擬環境（建議，可避免和電腦上其他 Python 套件衝突）。

Windows：

```
python -m venv .venv
.venv\Scripts\activate
```

macOS / Linux：

```
python3 -m venv .venv
source .venv/bin/activate
```

安裝相依套件：

```
pip install -r requirements.txt
```

確認安裝成功：

```
python -m twbacktest strategies
```

會列出所有內建策略。

（選用）執行測試：

```
pip install pytest
python -m pytest
```

## 3. 五分鐘快速上手

1. 先把台積電、元大台灣50、大盤近 5 年資料下載到本機：

   ```
   python -m twbacktest fetch 2330 0050 TAIEX
   ```

2. 用預設策略（20 日 / 60 日均線交叉）回測台積電。台積電股價高，一張可能超過預設的 100 萬本金，所以加上 `--lot 1` 允許零股：

   ```
   python -m twbacktest run 2330 --lot 1
   ```

3. 換成 RSI 策略，並自訂參數：

   ```
   python -m twbacktest run 2330 -s rsi -p lower=25 -p upper=75 --lot 1
   ```

4. 一次比較多檔股票：

   ```
   python -m twbacktest run 2330 2317 2454 0050 -s macd --lot 1
   ```

5. 回測大盤本身（加權指數）：

   ```
   python -m twbacktest run TAIEX -s sma_cross --benchmark none
   ```

每次 `run` 會在終端機印出績效，並在 `reports/` 資料夾產生一份報告，
用瀏覽器打開 `report.html` 就能看圖表與交易明細。

## 4. 資料來源與抓取規則

### 4.1 股票代號寫法

| 輸入 | 意義 |
|---|---|
| `2330` | 自動判斷：先試上市（2330.TW），再試上櫃（.TWO） |
| `2330.TW` | 上市股票 |
| `6488.TWO` | 上櫃股票 |
| `0050`、`00878` | ETF（自動套用 0.1% 證交稅） |
| `TAIEX`、`^TWII`、`大盤` | 台灣加權股價指數 |

### 4.2 抓取順序

1. **Yahoo Finance**（`yfinance` 套件）：價格已**還原權息**，上市、上櫃都有，速度快。
2. **臺灣證券交易所官網**：只有上市股票與加權指數，價格**未還原權息**。
   證交所有流量限制，程式每次請求間隔 3 秒，5 年資料約需 3 分鐘。
3. **本機快取**（`data_cache/` 資料夾）：每次成功抓到的資料都會存起來。

### 4.3 抓不到最新資料時的自動退回

依你的需求，系統會依序嘗試：

1. 你指定的期間（預設：**今天往前 5 年**）
2. 若失敗 → 改抓**近 5 年**
3. 若仍失敗 → 改抓**近 3 年**
4. 全部失敗 → 使用本機快取中已有的資料
5. 連快取都沒有 → 顯示錯誤，並建議改用 `--csv` 匯入資料

終端機會顯示實際使用的資料範圍與來源，例如：

```
資料：2330.TW：2021-10-12 ~ 2026-10-09，共 1215 筆，來源 yfinance（指定期間抓不到，改抓近 5 年資料）
```

### 4.4 離線使用

先用 `fetch` 下載過一次後，可以加 `--offline` 完全不連網：

```
python -m twbacktest run 2330 --offline
```

### 4.5 匯入自己的 CSV

如果網路抓不到，可以從券商軟體、證交所網站或其他地方下載 CSV 再匯入：

```
python -m twbacktest run 2330 --csv 我的台積電.csv --benchmark-csv 我的大盤.csv
```

CSV 至少要有「日期」與「收盤價」欄位，可接受以下欄位名稱（大小寫不拘）：

| 標準欄位 | 可接受的欄位名稱 |
|---|---|
| 日期 | `Date`、`日期`（支援西元 `2024-01-02` 或民國 `113/01/02`） |
| 開盤 | `Open`、`開盤價`、`開盤` |
| 最高 | `High`、`最高價`、`最高` |
| 最低 | `Low`、`最低價`、`最低` |
| 收盤 | `Close`、`收盤價`、`收盤` |
| 成交量 | `Volume`、`成交股數`、`成交量` |

缺少開高低時會用收盤價代替（停損停利的精準度會降低）。數字中的千分位逗號會自動移除。

### 4.6 指定資料來源

只用證交所：

```
python -m twbacktest run 2330 --source twse
```

只用 Yahoo Finance：

```
python -m twbacktest run 2330 --source yfinance
```

> 💡 **還原權息的重要性**：台股配息頻繁，未還原的價格在除權息日會出現「假跌」，
> 會讓策略誤判出場、低估報酬。建議優先使用 Yahoo Finance（預設）。

## 5. 指令說明

所有指令格式：`python -m twbacktest <指令> [參數]`，任何指令加 `-h` 可看說明。

### 5.1 `strategies`：列出策略

```
python -m twbacktest strategies
```

### 5.2 `fetch`：下載資料

```
python -m twbacktest fetch 2330 2317 0050 TAIEX
python -m twbacktest fetch 2330 --start 2020-01-01 --end 2024-12-31
```

### 5.3 `run`：執行回測

```
python -m twbacktest run <股票代號...> [選項]
```

| 選項 | 說明 | 預設 |
|---|---|---|
| `-s, --strategy` | 策略名稱 | `sma_cross` |
| `-p, --param` | 策略參數，可重複，例：`-p fast=10 -p slow=60` | 策略預設值 |
| `--start` / `--end` | 回測期間 `YYYY-MM-DD` | 近 5 年 ~ 今天 |
| `--capital` | 初始資金 | 1,000,000 |
| `--lot` | 交易單位：`1000` 整張、`1` 零股 | 1000 |
| `--position` | 每次進場投入現金比例（0~1） | 1 |
| `--discount` | 手續費折扣，六折填 `0.6` | 1（不打折） |
| `--min-fee` | 最低手續費 | 20 |
| `--tax` | 證交稅率 | 股票 0.003／ETF 0.001 |
| `--slippage` | 單邊滑價，例：`0.001` = 0.1% | 0 |
| `--stop-loss` | 停損，例：`0.1` = 跌 10% 出場 | 不設定 |
| `--take-profit` | 停利，例：`0.2` = 漲 20% 出場 | 不設定 |
| `--risk-free` | 無風險利率（計算夏普比率用），例：`0.015` | 0 |
| `--benchmark` | 比較基準，`none` 表示不比較 | `TAIEX` |
| `--benchmark-csv` | 用自備 CSV 當比較基準 | — |
| `--csv` | 用自備 CSV 當行情（只限單一股票） | — |
| `--source` | `auto`、`yfinance`、`twse` | `auto` |
| `--offline` | 只用本機快取 | 關閉 |
| `--out` | 報告輸出資料夾 | `reports` |
| `--no-report` | 不產生報告檔 | 關閉 |
| `-v` | 顯示除錯訊息（放在指令前：`python -m twbacktest -v run ...`） | 關閉 |

**範例：**

小資族：本金 10 萬、零股、手續費六折、最低 1 元：

```
python -m twbacktest run 2330 --capital 100000 --lot 1 --discount 0.6 --min-fee 1
```

加上 8% 停損、25% 停利，並模擬 0.1% 滑價：

```
python -m twbacktest run 2454 -s breakout --stop-loss 0.08 --take-profit 0.25 --slippage 0.001
```

指定期間，只投入一半資金：

```
python -m twbacktest run 2317 -s kd --start 2022-01-01 --end 2024-12-31 --position 0.5
```

### 5.4 `optimize`：參數最佳化

```
python -m twbacktest optimize <股票代號> -s <策略> -g <參數=值...> [選項]
```

| 選項 | 說明 |
|---|---|
| `-g, --grid` | 參數範圍，可重複。列舉：`fast=5,10,20`；範圍：`slow=40:120:20`（起:迄:間隔，含迄） |
| `--metric` | 排序依據：`sharpe`（預設）、`cagr`、`total_return`、`calmar`、`win_rate` |
| `--split` | 樣本內比例，例：`0.7`（詳見第 9 節） |
| `--top` | 顯示前幾名（預設 10） |
| `--save` | 完整結果存成 CSV |

`run` 的交易設定選項（`--capital`、`--lot`、`--discount`…）在 `optimize` 也都能用。

```
python -m twbacktest optimize 2330 -s sma_cross -g fast=5:30:5 -g slow=40:120:20 --split 0.7 --lot 1
```

## 6. 內建策略

所有策略都是「只做多」：訊號 1 = 持有，0 = 空手。

| 名稱 | 策略 | 規則 | 預設參數 |
|---|---|---|---|
| `buy_hold` | 買進持有 | 第一天買進一路持有，當作比較基準 | — |
| `sma_cross` | 均線交叉 | 短均線 > 長均線時持有 | `fast=20, slow=60` |
| `ema_cross` | 指數均線交叉 | 同上，改用 EMA，反應較快 | `fast=12, slow=26` |
| `rsi` | RSI 超買超賣 | RSI < lower 買進，RSI > upper 賣出 | `period=14, lower=30, upper=70` |
| `macd` | MACD 交叉 | DIF > 訊號線（DEA）時持有 | `fast=12, slow=26, signal=9` |
| `bollinger` | 布林通道均值回歸 | 收盤跌破下軌買進，站回中軌賣出 | `period=20, k=2` |
| `kd` | KD 指標 | K 在超賣區黃金交叉買進，在超買區死亡交叉賣出 | `n=9, oversold=20, overbought=80` |
| `breakout` | 通道突破（海龜） | 收盤突破前 entry 日高點買進，跌破前 exit 日低點賣出 | `entry=20, exit=10` |

**策略類型小提醒：**

- **趨勢追蹤型**（`sma_cross`、`ema_cross`、`macd`、`breakout`）：適合大漲大跌、有明顯趨勢的股票，盤整時容易來回被洗。
- **均值回歸型**（`rsi`、`bollinger`、`kd`）：適合區間震盪的股票，遇到單邊大跌可能越買越套，建議搭配 `--stop-loss`。

## 7. 交易規則與成本設定

### 7.1 成交規則（避免「偷看未來」）

1. 第 t 日**收盤後**依策略計算訊號。
2. 第 t+1 日以**開盤價**成交。
3. 停損／停利：盤中最低價（或最高價）觸及設定價格就出場，成交價為觸發價；
   若開盤就跳空越過，則以開盤價成交（較貼近真實情況）。
   停損停利出場後，要等策略訊號先轉為空手、再轉回持有，才會重新進場，避免隔天馬上又買回。
4. 每日以收盤價計算資產淨值（含未實現損益）。

### 7.2 台股交易成本

| 項目 | 計算方式 | 本系統預設 |
|---|---|---|
| 券商手續費 | 成交金額 × 0.1425% × 折扣，買賣各收一次，未滿最低金額以最低金額計 | 不打折、最低 20 元 |
| 證券交易稅 | 賣出成交金額 × 稅率 | 股票 0.3%；代號 `00` 開頭的 ETF 0.1% |
| 滑價 | 買進價 × (1 + 滑價)、賣出價 × (1 − 滑價) | 0 |

手續費與證交稅都無條件捨去到整數元。
不打折時，股票一買一賣的成本約 0.585%，ETF 約 0.385%。

**依自己的券商調整：**

- 網路下單常見六折 → `--discount 0.6`
- 零股交易最低手續費常為 1 元 → `--lot 1 --min-fee 1`
- 債券 ETF 若免證交稅 → `--tax 0`
- 交易量小或冷門股，建議加 `--slippage 0.001` 以上，結果會比較保守

### 7.3 整張與零股

- `--lot 1000`（預設）：只能買整張，資金不足一張時不會進場，終端機會提示次數。
  例如 10 萬元無法買 1 張股價 500 元的股票。
- `--lot 1`：允許零股，適合小額資金或高價股。

> ⚠️ **高價股要特別注意**：例如股價超過 1,000 元的台積電，一張就超過預設本金 100 萬，
> 整張模式下會一直買不起而空手，報酬會被嚴重低估。看到「資金不足…未進場」的提醒時，
> 請加上 `--lot 1` 或提高 `--capital` 重跑。`run` 和 `optimize` 都會顯示這個提醒，
> `optimize` 的結果表中 `skipped` 欄位就是未進場次數。

## 8. 看懂回測報告

每次 `run` 會在 `reports/<代號>_<策略>_<時間>/` 產生：

| 檔案 | 內容 |
|---|---|
| `report.html` | **用瀏覽器開啟**：圖表＋績效指標＋設定＋交易明細 |
| `chart.png` | 三張圖：股價與買賣點、資產曲線 vs 大盤、回撤 |
| `equity.csv` | 每日現金、持股、收盤價、資產淨值、訊號 |
| `trades.csv` | 每筆交易（可用 Excel 開啟） |
| `summary.json` | 指標與設定（方便程式讀取） |

### 績效指標說明

| 指標 | 意義 | 怎麼看 |
|---|---|---|
| 總報酬率 | 期末資產 ÷ 初始資金 − 1 | 越高越好 |
| 年化報酬率 (CAGR) | 換算成每年平均複利報酬 | 跟大盤年化報酬比較 |
| 年化波動率 | 每日報酬的標準差 × √252 | 越低代表淨值越平穩 |
| 夏普比率 | (年化報酬 − 無風險利率) ÷ 年化波動率 | > 1 不錯，> 2 很好 |
| 索提諾比率 | 只用下跌波動計算的夏普比率 | 越高越好 |
| 最大回撤 (MDD) | 從最高點到最低點的最大跌幅 | 想想自己能不能承受 |
| 最長回撤期間 | 淨值低於前高的最長連續交易日數 | 越短越好 |
| 卡瑪比率 | 年化報酬率 ÷ 最大回撤 | > 1 不錯 |
| 持倉時間比例 | 有持股的天數比例 | 低代表資金常閒置 |
| 交易次數 | 已平倉的交易筆數 | 太少代表統計意義不足 |
| 勝率 | 賺錢交易 ÷ 總交易 | 要和獲利因子一起看 |
| 獲利因子 | 總獲利 ÷ 總虧損 | > 1.5 不錯 |
| 手續費＋證交稅合計 | 全部交易成本 | 交易越頻繁越高 |
| 大盤同期報酬率 | 同期間買進持有大盤的報酬 | 策略該打敗它 |
| 超額報酬 | 策略總報酬 − 大盤總報酬 | 正值代表贏大盤 |
| Alpha | 扣除大盤影響後的年化超額報酬 | 正值越大越好 |
| Beta | 策略對大盤漲跌的敏感度 | 1 = 跟大盤同步；< 1 = 波動較小 |

交易明細中，若期末仍持有股票，會標記為「**期末持有中（估算）**」，損益以最後收盤價並扣除假設的賣出成本估算，
**不計入**交易次數與勝率。

## 9. 參數最佳化與避免過度擬合

最佳化會把每一組參數都跑一次並排名。**但歷史上最好的參數，未來不一定好**（過度擬合）。

建議一律加上 `--split 0.7`：

- 前 70% 的資料（**樣本內**）用來挑最佳參數
- 後 30% 的資料（**樣本外**）用來驗證這組參數，程式只用它跑一次

```
python -m twbacktest optimize 2330 -s rsi -g period=7,14,21 -g lower=20:35:5 -g upper=65:80:5 --split 0.7 --lot 1
```

判讀方式：

- 樣本外表現**接近**樣本內 → 參數比較可靠
- 樣本外表現**大幅變差** → 很可能是過度擬合，不要直接採用
- 排名前幾名的參數彼此**相近**（例如 fast=10、15、20 都不錯）→ 策略較穩健；
  若只有某個特定數字特別好，通常是巧合

無效的參數組合（例如 `fast >= slow`）會自動略過。

如果樣本外顯示 **0 筆交易、0% 報酬**，先看下方有沒有「資金不足…未進場」的提醒。
樣本外會用初始資金重新開始，高價股在整張模式下可能根本買不起，這時請加上 `--lot 1` 重跑。

### 10.3 自訂策略

策略就是一個「輸入行情 DataFrame、輸出 0/1 序列」的函式：

```python
import pandas as pd
from twbacktest import BacktestConfig, CostModel, compute_metrics, get_history, run_backtest
from twbacktest import indicators as ind

def my_strategy(df: pd.DataFrame) -> pd.Series:
    """收盤站上 60 日均線且 RSI < 70 時持有。"""
    above = df["close"] > ind.sma(df["close"], 60)
    not_hot = ind.rsi(df["close"], 14) < 70
    return (above & not_hot).astype(float)

prices, _ = get_history("2330")
bench, _ = get_history("TAIEX", start=prices.index[0], end=prices.index[-1])

config = BacktestConfig(initial_capital=1_000_000, lot_size=1000,
                        costs=CostModel(commission_discount=0.6), stop_loss=0.1)
result = run_backtest(prices, my_strategy(prices), config)
print(compute_metrics(result, benchmark=bench["close"]))
```

若想讓自訂策略也能用命令列執行，可在 `twbacktest/strategies.py` 最下方的 `STRATEGIES` 清單中，
仿照現有寫法加一行 `Strategy(...)`。

## 11. 常見問題

**Q：出現「無法取得 XXXX 的行情資料」？**
1. 確認網路能連到 `query1.finance.yahoo.com` 或 `www.twse.com.tw`（公司網路可能會擋）。
2. 加 `-v` 看詳細錯誤：`python -m twbacktest -v run 2330`
3. 試試 `--source twse`。
4. 仍不行就從其他地方下載 CSV，用 `--csv` 匯入。

**Q：證交所抓很久？**
證交所限制請求頻率，每月資料要一次請求、間隔 3 秒。建議先 `fetch` 一次，之後用 `--offline`。
若被證交所暫時封鎖，等幾分鐘再試。

**Q：Windows 出現「'#' 不是內部或外部命令」？**
`#` 是 macOS / Linux 終端機的註解符號，Windows 命令提示字元不認得。
這個錯誤不影響其他指令，可以忽略；本手冊的指令區塊已不含註解，直接逐行貼上即可。

**Q：為什麼沒有任何交易？**
- 資金不足一張：改用 `--lot 1` 或提高 `--capital`。
- 回測期間太短，指標還沒算出來（例如 60 日均線至少需要 60 天資料）。
- 策略條件太嚴格，可放寬參數。

**Q：證交所和 Yahoo 的價格不一樣？**
Yahoo 是還原權息價格，證交所是實際成交價。兩者在除權息日之前的價格會有差距，屬正常現象。

**Q：可以做空、當沖或融資嗎？**
目前只支援現股做多。當沖證交稅減半（0.15%），可用 `--tax 0.0015` 粗略模擬，但引擎仍是隔日開盤成交，並非真正的當沖。

**Q：報告的圖表為什麼是英文？**
為了避免電腦缺少中文字型時出現亂碼方塊，圖表標籤使用英文；HTML 報告內的文字與表格是中文。

**Q：快取資料存在哪？可以刪嗎？**
在 `data_cache/` 資料夾，可以直接刪除，下次會重新下載。可用環境變數 `TWBT_CACHE` 指定其他位置。
